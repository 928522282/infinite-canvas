# 关键帧生图提示词｜资产强约束版

# 15s脚本关键帧生成｜资产强约束模式

## 核心任务

针对一个不超过15秒的当前VID，选择两个视觉差异最大的真实镜头，分别生成可独立送入生图模型的 `KF-A` 与 `KF-B` 提示词。通过人物身份、场景坐标、表演和光影四类资产绑定，使不同景别与机位下的角色骨骼结构、妆造和场景布局仍严格继承已确认参考图。

本Skill只编写提示词，不执行实际生图、视频生成、资产管理或脚本改写。

## 输入门禁

执行前必须完整读取：

- 当前VID的完整15秒内脚本、所属SCENE上下文、Shot编号、时间点、人物动作、逐字台词、道具状态和结束状态；
- `script-character-asset-audit` 已审核PASS的当前VID人物资产白名单，包含 `character_id`、`canonical_name`、`asset_id` 与实际参考节点；
- 当前场景、服装、配饰和关键道具的已确认资产及实际参考节点。

必须实际查看参考图，再提取五官、发型、妆造、家具、门窗、材质、光源和透视信息。不得用文件名、文字标签或通用审美词代替看图。必要资产缺失、匹配不唯一、图片无法读取、人物资产互相冲突，或所需机位超出场景资产能够证明的空间范围时，输出最小 `BLOCK` 清单并停止，不得脑补。

## 一、资产至上原则

1. **资产是事实边界**：文字描述不得违背已确认人物、场景、服装、配饰和道具资产。严禁根据“美貌”“帅气”“豪华”“高级”等形容词引入模型自带脸型、装潢或物件。
2. **禁止重构场景**：门、窗、墙面开口、床、柜、桌椅和其他主要家具建立固定坐标系。机位变化只能改变观察角度、透视、遮挡和画面取舍，不能增删、移动、复制或重新设计固定物体。
3. **身份锁定**：人物描述必须来自资产图中实际可见的骨骼和五官结构，包括脸部轮廓、眼型与眼距、眉形、鼻梁与鼻头、唇形、下颌角、耳形及稳定识别特征。禁止用模糊审美词代替这些特征。
4. **妆造锁定**：逐人复述资产中实际可见的发型分缝方向、发长、发量、碎发、发色、妆面、服装版型、面料、颜色、层次、鞋履和配饰；只有脚本明确换装时才允许改变。
5. **资产不新增剧情**：参考图只提供视觉身份与物理空间依据，剧情、动作、人物关系、道具归属和结果仍以当前VID及其上游事实为准。

先在内部建立本VID的资产不变量表：人物身份特征、妆造、场景固定物、物体相对位置、主光源方向和允许变化项。最终Prompt必须完整展开这些不变量，不得输出“同上”“沿用前帧”或只引用表格。

## 二、选择两张独立关键帧

- `KF-A` 与 `KF-B` 必须来自当前VID两个真实存在且不同的Shot，A早于B。
- 优先选择叙事作用重要、视觉差异最大的两个冻结瞬间。差异应来自景别、机位、人物表演、动作状态、遮挡关系或光影位移，不得来自换脸、改发型、换装、搬动家具或改变墙面。
- 两帧必须形成可追溯的前后剧情关系，但每帧提示词都要自足并能单独执行。
- 两帧只是同一构图的轻微表情变化时重新选择；若当前VID没有两个有效独立Shot，则明确 `BLOCK`，不得虚构第二个镜头。

## 三、严格绑定技术

### 1. 人物身份锁定（Anti-Face Drift）

每个可见固定人物都必须写明：

- `character_id + canonical_name + asset_id + 实际参考节点`；
- 基于资产图实际提取的脸部轮廓、眼型眼距、鼻型、唇型、下颌角、发型分缝、碎发、发色和关键配饰；
- 身体朝向、头部角度、视线目标、双手、与其他人物及道具的接触关系；
- “保持资产图中该角色的同一骨骼结构与身份”的正向约束。

多人画面逐人展开，禁止使用“众人”“其他人物”或将一个人的特征套给另一人。不得使用“精致五官”“漂亮”“帅气”等会诱发通用脸的词。

### 2. 场景空间锚点（Spatial Invariance）

每帧至少选择一个场景资产中真实可见、位置稳定的大件作为坐标原点，并写明：

- 摄影机相对锚点的方向、高度、距离区间和水平夹角；
- 人物相对锚点、门窗和其他固定家具的左/右、前/后、远/近关系；
- 前景、中景、背景的遮挡顺序，以及机位改变后哪些固定物体进入或退出画面；
- 与资产空间深度相符的焦段、镜头高度和透视强度。

不同机位下必须从同一物理布局推演新的透视遮挡，不能把参考图看不到的区域擅自设计成新房间。

### 3. 表演与微表情

表情只能在已锁定脸型上做肌肉定向变化。逐角色说明眉间、上眼睑、下眼睑、鼻翼、嘴角、唇部开合、下颌和颈部张力的可见变化；可使用与画面相符的近似角度或位移方向，但不得用夸张数值改变骨骼结构。

视线必须落到画面中实际存在的人物、道具或场景坐标点；不能写“望向远方”等无坐标目标。

### 4. 物理光影绑定

- 继承场景资产中实际存在的窗户、门洞、灯具或其他主光源方向、色温和软硬程度；
- 根据固定家具与人物位置推演阴影在地面、墙面和物体上的投影方向、长度与遮挡；
- KF-A与KF-B允许因人物和摄影机移动出现合理的明暗变化，但不能让窗户、灯具或主光方向无原因换边。

## 四、负面提示词

每帧保留简短基础限制：“不增删人物；不出现明显手部错误、字幕、Logo或水印。”并必须加入以下防漂移专项词：

`(changing facial features:1.5), (face morphing:1.5), (wrong ethnicity), (wrong age), (deforming skeleton), (rearranging furniture), (new room layout), (changing wall colors), (extra windows), (teleporting props)`

只允许再补充一项与当前镜头直接相关的坐标、跳轴或遮挡风险，不堆叠无关通用负面词。

## 五、固定输出格式

只输出以下交付物，不输出内部分析：

```markdown
# 15s脚本关键帧生成｜资产强约束模式

## KF-A｜镜头编号：Shot 0x

剧情节点：[冻结瞬间与来源时间点]

资产绑定：角色资产[character_id / canonical_name / asset_id / 实际参考节点]；场景资产[asset_id / 实际参考节点]

### 独立生图提示词（Production-Grade）

1. [身份与服装锁定]：逐角色完整展开资产中的骨骼、五官、发型、妆造、服装与配饰。
2. [空间坐标锚点]：说明摄影机、人物、门窗、固定家具和道具相对锚点的位置与遮挡。
3. [构图与机位]：景别、角度、焦段、镜头高度、透视和画面取舍。
4. [逐角色表演控制]：按人物顺序描述动作、视线目标和表情肌变化。
5. [光影材质推演]：继承资产光源并说明阴影、反射、皮肤、发丝、面料和道具材质。

### 负面提示词

[简短基础限制 + 强制防漂移专项词 + 至多一项当前镜头风险]

---

## KF-B｜镜头编号：Shot 0y

剧情节点：[与A帧不同的叙事时刻与来源时间点]

资产绑定：[重新完整列出，不写“同上”]

### 独立生图提示词（Production-Grade）

[重新完整展开全部五部分，重点说明机位改变后同一固定家具产生的新透视与遮挡关系；不得引用KF-A代替正文。]

### 负面提示词

[简短基础限制 + 强制防漂移专项词 + 至多一项当前镜头风险]
```

## 六、输出前自检

输出前逐项确认：

- Prompt没有用模糊审美词替代资产中的具体脸部结构；人物资产绑定没有串人、漏人或混用造型。
- KF-A与KF-B的固定家具、门窗、墙色、空间轴线和道具逻辑仍属于同一场景坐标系。
- 机位、焦段、透视和遮挡能够由已确认场景资产推导，没有补造看不见的空间。
- 主光源来自资产中的物理开口或灯具，阴影落点与人物和家具位置一致。
- 两帧视觉差异来自镜头与表演，而不是身份、妆造或场景漂移。
- KF-B全文独立展开，没有“同上”“保持上一张”或省略资产事实。

任何一项不能确认时输出最小 `BLOCK` 清单，不得假装通过。
