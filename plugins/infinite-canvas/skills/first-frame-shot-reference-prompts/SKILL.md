# 首帧与重要镜头参考图提示词

## 核心任务

完整读取当前SCENE以掌握上下文和连续性，然后只针对当前指定的VID执行以下工作：

1. 生成1张严格对应当前VID `0.00秒` 的首帧生图提示词，标记为 `KF-START`。
2. 从当前VID后续镜头中选择若干真正影响剧情理解、人物状态、构图或空间关系的重要时间点，分别生成独立生图提示词，标记为 `KF-REF-01`、`KF-REF-02`……。
3. 为每张参考图记录其所属 `Shot`、精确时间点和编译器引用职责，使“优化视频镜头提示词编译器”能在对应镜头和时间点引用该图片。

本Skill不生成尾帧。最后一张重要镜头参考图也不能自动当作尾帧，除非其他上游流程另有明确指定。

“当前SCENE完整内容”和“当前目标VID”是上游自动注入的输入槽位，不是要求用户重新粘贴的固定文字。优先读取上游已提供的SCENE、VID、镜头和SRC；只有缺少目标VID或缺少会改变画面主体与结构的必要事实时，才要求补充。

## 工作单位与读取范围

- 以一个 `VID-xxx` 为一次实际输出单位，不以整个SCENE为一组只生成一次图片。
- 必须完整读取当前SCENE下的全部VID、全部镜头、全部关联SRC及人物、服装、场景、道具信息，以确认前后状态和连续性。
- 图片选择和输出只针对当前指定的VID。不得从其他VID选择画面冒充当前VID参考图。
- 上一VID的结束状态用于确定当前VID的首帧；当前VID后续状态不得提前出现在 `KF-START`。

不得先选镜头再只读取选中镜头附近的信息，也不得用摘要、上一轮提示词或单个VID片段代替完整场景上下文。

## 事实优先级

剧情与动作事实按以下顺序确定：

1. 原始编导文本及SRC。
2. 当前VID和镜头设计。
3. 上一VID结束状态及当前VID开始状态。
4. 已确认的人物、服装、场景和道具资产。

原文、VID、镜头和SRC决定剧情、动作、人物关系、道具归属与结果；资产图只提供身份、外貌、发型、服装、材质、场景结构、空间、色彩和造型依据。不得由资产图新增剧情事实。

任何关键帧与上游事实或已确认资产发生明显冲突时，先指出冲突并停止，不能自行选择一个版本、改写剧情或重做资产。

## 上传资产轻量匹配

处理文本时，将当前VID中的人物和场景与已上传资产按名称匹配：

- 人物按剧本人物名匹配同名人物资产。
- 场景按场景名称匹配标注为“XX场景”的同名场景资产。
- 道具有同名资产时，按道具名称和当前状态匹配。
- 同一人物有多套造型时，依据当前剧情阶段、发型、服装和配饰选择唯一一致的造型，不得混用。

匹配成功后，资产中可见的人物身份特征、外貌、发型、服装、配饰，以及场景结构、空间关系、色彩和材质，必须进入每张相关图片的独立生图提示词。

名称重名、匹配不唯一、必要资产缺失或资产与文本明显冲突时，必须要求确认，不得猜测。这里只做名称匹配和视觉引用，不建立资产ID、命名规范化、扫描、重命名或其他资产管理流程。

## KF-START首帧要求

`KF-START`必须是当前VID的实际第 `0.00秒` 完整画面，而不是人物设定图、场景概念图、剧情高光图或中间镜头。

首帧必须准确呈现：

- 当前VID开始时实际可见的人物及其身份、外貌、发型、服装和配饰。
- 每个人物的前后景、左右位置、身体朝向、视线、姿态、表情和双手状态。
- 动作开始前或刚被触发时的准确状态，不提前呈现后续动作结果。
- 道具的外观、数量、位置、持有人、接触关系和起始状态。
- 场景结构、空间边界、门窗、家具、地面、背景和人物与场景的比例关系。
- Shot 1在0.00秒规定的景别、机位、镜头高度、角度、构图、光源方向、色彩和材质。

首帧构图必须能够自然启动当前VID后续已经规定的动作和运镜。不得为了增强冲击力，擅自把后续人物、道具、结果或反应提前放入首帧。

## 重要镜头参考图选择

除 `KF-START` 外，从当前VID的后续Shot中选择真正需要图片锁定的重要状态。通常选择1—3张；以剧情与控制需求为准，不机械凑数，也不遗漏会显著影响H3理解的关键镜头。

优先选择：

- 新人物首次清晰出现或人物组合发生重要变化的镜头。
- 冲突触发、证据出现、道具状态改变或信息揭示的画面。
- 机位、构图、空间关系或主体位置发生显著变化且仅靠文字容易产生歧义的镜头。
- 关键表情反应、动作接触、人物对峙或阶段性结果。
- 后续视频必须准确复现的产品、UI、文字、特殊道具或视觉状态。

不选择：

- 与首帧或其他参考图内容重复、只存在轻微表情差异的画面。
- 没有剧情、动作、表情、空间、道具或构图变化的过渡画面。
- 当前VID之外的剧情节点。
- 无法对应到具体Shot和时间点的概括性画面。

重要参考图不承担尾帧职责。每张图必须明确写明：

- 所属镜头，例如 `Shot 3`。
- 对应时间点，例如 `00:07.50`。
- 控制维度，例如人物位置、动作状态、构图、道具、UI或表情。
- 优化视频镜头提示词编译器在该Shot和时间点引用该图，不将其解释为视频首帧或尾帧。

## 视觉事实完整展开

生成每张图片前，核对该时间点已有的：人物身份、外貌、发型、服装、配饰、位置、朝向、视线、动作、表情、双手、人物关系、关键道具、场景结构、空间边界、景别、机位、构图、光影、色彩和材质。

原文、VID、镜头、SRC或资产中已经明确且在当前画面可见的信息，必须重新完整写进该图片的独立生图提示词。不得使用“众人”“其他人物”“同上”“沿用首帧”“保持上一张”或类似省略表达。

多人画面逐人说明：

- 姓名、身份、外貌、发型、服装和配饰。
- 左右、前后景、距离、姿态、身体朝向和视线。
- 双手动作、表情、接触对象及与道具和场景的关系。

每张提示词必须能够脱离其他图片提示词独立送入生图模型。不得因为某项信息已在首帧、内部分析或其他参考图出现而省略。

原文或资产没有提供的信息不得为了画面丰富而虚构。缺失但不改变身份和剧情的普通环境细节，可以使用克制且不与现有事实冲突的描述。

## 跨帧身份参考与一致性门禁

- 按KF-START、KF-REF-01、KF-REF-02的顺序逐张生成，不得并行。每张正向提示词开头必须明确写出 `character_id + canonical_name + asset_id + 实际参考节点` 的人物绑定。
- 每张图始终使用审核PASS的权威原始人物资产。KF-START若存在包含同一人物的上一张确认图，也把它作为身份连续性参考；后续每张继续使用相同权威资产，并增加紧邻的上一张已确认图。上一张图只锁定重叠人物的脸、发型、体型、已确认服装配饰与连续状态，不能覆盖权威资产或新增剧情。
- 若上一张确认图不含当前人物，使用该人物最近一张已确认图；仍不存在时只使用该人物的权威原始资产，不把无关人物图硬塞为身份参考。
- 每张生成结果都建立画布原生多模态文本校验节点，把当前结果图、权威原始资产和上一张身份参考图作为真实图片输入；首行只输出PASS或BLOCK，再按character_id简述实际可见人物集合、脸、发型、体型、服装变体和关键配饰差异。无法读取图片或无法确认时按BLOCK处理。只有生成成功且校验PASS的图片才标记为确认图并进入下一张；不一致、人物增删或无法辨认时阻断当前VID。
- 每张提示词仍须完整、自足，不得用“沿用上一张”代替正向画面描述。

## 优化视频镜头提示词编译器交接要求

- `KF-START`固定绑定当前VID `Shot 1 / 0.00秒`。
- 每张 `KF-REF`固定绑定一个真实存在的Shot和精确时间点。
- 所有图片使用与当前VID相同的画幅和方向，尺寸比例保持一致。
- 同一人物在全部图片中的脸、体型、发型、服装和配饰保持一致，除非VID明确规定变化。
- 场景结构、光源方向、空间轴线和关键道具连续；镜头切换可以改变景别和机位，但必须符合VID镜头设计。
- 图片只锁定对应时刻的画面状态，不替代VID中的动作过程、运镜、对白或声音。
- 优化视频镜头提示词编译器必须从完整VID脚本读取图片之间发生的动作和声音，不得根据图片自行补写剧情。
- 不把最后一张 `KF-REF`解释为结束帧，也不要求最终视频收敛到该图片。

## 写实质感与文字限制

正文呈现真实皮肤毛孔、细小汗毛、唇纹、眼周纹理、真实发丝、布料纹理、道具材质、接触阴影和符合场景的光线反应，避免塑料感、蜡像感和明显CG感。

不新增字幕、UI、水印、Logo、乱码或无意义文字。原文、VID、镜头或SRC明确要求可见的剧情UI、证据文字、产品Logo和道具标识必须准确保留，不能被负面提示词误删。

负面提示词保持简短且只针对真实风险，默认使用：“不改变人物身份、脸、发型与已确认服装；不增删人物；不出现明显手部错误、字幕或水印。”仅当当前画面存在明确额外风险时补充一项，不堆叠无关通用负面词。

## 固定输出格式

只输出当前VID的首帧与重要镜头参考图提示词，不输出内部分析，不执行实际生图，不编写优化视频镜头Prompt。

# SCENE-001｜VID-001｜首帧与重要镜头参考图提示词

剧情节点：……

编译器引用职责：当前VID的实际0.00秒首帧；生成并上传后，使用其真实素材标记在优化视频镜头提示词中绑定Shot 1 / 0.00秒。

重新完整展开该参考图全部有效视觉事实，不引用KF-START。

按实际需要继续输出 `KF-REF-03` 等参考图；没有必要时不得机械增加。

实际图片上传目标视频生成平台后，以平台生成的真实素材标记替换说明中的图片名称。不得预先虚构 `@图片1`、`@图片2` 等不存在的素材引用。

## 完成边界

唯一交付物是当前目标VID的1段 `KF-START` 独立首帧生图提示词和若干段 `KF-REF` 独立重要镜头参考图提示词，以及每张图对应的Shot、时间点和编译器引用职责。

不得生成尾帧，不执行实际生图、优化视频镜头Prompt编译、视频生成、资产管理、机器验证、评分质检、视频脚本修改或其他后续流程。
