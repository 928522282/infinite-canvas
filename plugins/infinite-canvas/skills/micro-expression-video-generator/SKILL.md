# 人物微表情表演增强

## 职责

为单个已拆分完成的VID补充可直接交给下游视频提示词编译器的“分时表演层”。重点设计眼神、眉眼、口周、下颌、吞咽、呼吸、头颈、肩膀以及必要的轻微手部或道具动作，让克制、破防、心动、犹豫、含泪强撑等复杂情绪具有真实演员式的变化。

本Skill不改写剧情，不重新拆镜，不生成图片或视频，不调用任何外部视频工具，不选择模型，不重试，也不自动切换渠道。

## 输入

每次只处理一个VID，并读取：

- 当前VID完整文本、所属SCENE上下文、原始SRC和上一VID结束状态；
- 已确认的人物资产、当前VID首帧与重要镜头参考图；
- 既有时长、景别、机位、运镜、人物调度、逐字台词、声音和结束状态。

优先从当前VID读取镜头时长与表演强度。只有目标演员、可见面部、镜头时长或关键情绪事实缺失到无法设计表演时，才输出最小阻断项；不得在每个VID重复要求用户确认已经存在的信息。

## 事实锁定

以下内容必须保持不变：

- character_id、人物身份、脸、年龄、体型、发型、已确认服装和配饰；
- 场景、人物位置、动作结果、道具归属、镜头数量、切点、景别、机位和运镜；
- 原始逐字台词、说话人、声音环境和VID结束状态。

确认图只提供该时刻的身份、初始表情、姿态和连续状态，不能覆盖原始人物资产或新增剧情。参考图、VID和SRC冲突时列出最小冲突并阻断，不自行选择版本。

## 表演设计

1. 先确定人物想让别人看到的外在面具，以及真正隐藏的情绪。
2. 根据当前镜头时长设计“基线 → 短暂泄露 → 主动压回 → 改变后的收束状态”。
3. 选择2—5个能够被镜头看见、与台词和动作兼容的细节，按时间先后展开；不要把眼神、眉眼、口周、呼吸、吞咽、手部和身体变化全部同时堆入一个短镜头。
4. 微表情使用正常物理速度。5—7秒镜头通常安排4—6个短节拍，避免所有动作都写成“缓慢”“慢慢”或长时间静止。
5. 对白存在时，表演节拍服从逐字台词和口型时机，不增加停顿、改词或让表情动作妨碍发音。
6. 多人镜头明确主表演者；只在听者反应影响剧情理解时补充一个克制反应，不让所有人物同时表演同一情绪。
7. 悲伤、失去、背叛、克制或麻木不能在结尾自动变成释然、温暖或微笑；笑容若是社交面具，必须说明它何时不稳定或消失。

## 连续性

- 当前表演从已确认首帧的真实状态开始，并自然到达VID规定的结束状态。
- 同一人物跨镜头保持脸、发型、服装、配饰和表演强度连续。
- 不用抽象的“很难过”“非常愤怒”代替可见动作，也不把微表情夸大成大幅哭喊、摇头、后退或无依据的肢体表演。
- 正向描述承担主要控制。针对性限制默认只写：“不改变人物身份、脸、发型、服装与原镜头；不把微表情夸大为大幅表演。”只有当前镜头存在明确额外风险时再补充一项。

## 固定输出格式

```text
# SCENE-xxx｜VID-xxx｜人物微表情表演层

来源：原始VID节点、SRC、首帧及重要镜头确认图的真实节点标记
镜头时长：
主表演者：character_id｜姓名
表演强度：克制 / 中等 / 强烈，以及来自剧本的依据
外在面具：
隐藏情绪：

## 分时表演
- 00:00.00—：基线状态……
- ……：短暂泄露……
- ……：主动压回……
- ……：收束状态……

对白与口型承接：
身份与画面连续性：
针对性限制：
下游编译器交接：只把以上内容作为当前VID的表演层，与原VID、确认资产和参考图共同编译；不得覆盖镜头与剧情事实。
```

一次输入含多个VID时，逐VID分别输出，不合并表演时间线。没有可见面部或该VID不需要微表情增强时，仍保留该VID结果并写明“N/A：沿用原表演，不新增微表情节拍”。

## 完成边界

唯一交付物是当前VID可追溯、可计时的微表情表演层。不得执行视频生成、模型选择、失败重试、口型编辑、完整编剧、面部绑定或最终合成。
