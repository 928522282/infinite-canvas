# 删除远程提示词来源与缓存设计

## 目标

先完成提示词库改造的清空阶段：保留现有提示词中心页面、搜索、筛选、详情、复制、加入素材和插入画布等使用能力，但移除当前所有远程提示词来源，并删除这些来源已经写入浏览器的提示词缓存。

本阶段不实现本地提示词的新增、编辑和删除管理页。

## 范围

### 删除

- 删除 7 个默认远程提示词来源预设。
- 升级提示词来源的本地持久化版本，使已有浏览器中保存的远程来源不再恢复。
- 在版本升级时执行一次提示词缓存清理，清空 IndexedDB 中 `infinite-canvas` 数据库的 `prompt_cache` store。
- 清理完成后，提示词中心显示 0 条提示词和现有空状态。

### 保留

- `/prompts` 路由和现有页面布局。
- 提示词卡片、详情弹窗、搜索、分类、标签、复制、加入素材及画布插入接口。
- “我的素材”、画布、生成记录、API 配置和其他浏览器本地数据。
- 现有远程来源管理入口及自定义 JSON 来源能力；本阶段只清空目前已配置的来源，不重做管理能力。

## 数据行为

1. 新安装或新浏览器的默认提示词来源为空数组。
2. 已使用旧版本的浏览器首次打开新版本时：
   - 丢弃旧版持久化的全部提示词来源；
   - 清空 `prompt_cache`；
   - 记录迁移已经完成，后续启动不重复执行清理。
3. 清理操作只作用于提示词来源配置和 `prompt_cache`，不得清理应用其他 localStorage 或 IndexedDB 数据。
4. 清理后提示词查询返回空列表、空分类和空标签，不发起远程提示词请求。

## 界面行为

- 提示词中心标题、搜索框和整体布局保持不变。
- 总数显示为 0。
- 内容区显示现有“暂无提示词”空状态。
- 配置中的提示词来源列表为空，用户仍可手动添加自定义来源。

## 错误处理

- 缓存清理失败不得阻塞应用启动或其他页面使用。
- 清理失败时，旧来源仍不会恢复，因此旧缓存不会被查询或展示。
- 后续再次启动可继续尝试未完成的缓存清理；只有清理成功后才记录迁移完成。

## 验收标准

- 新浏览器打开提示词中心时显示 0 条提示词，且没有默认来源。
- 从旧版本升级后，原有 7 个默认来源和用户此前配置的远程来源均不再出现。
- 升级后 `prompt_cache` 中不再保留旧提示词缓存。
- 提示词中心、配置页、画布、我的素材及其他页面可以正常打开。
- “我的素材”、画布项目、生成记录和 AI 配置不受影响。

## 后续阶段

后续单独设计并实现浏览器本地提示词数据与独立管理页，支持逐条新增、编辑和删除；不纳入本次清空改动。
